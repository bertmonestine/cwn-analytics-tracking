# Metrics Glossary

| Metric | Plain-English meaning |
|---|---|
| Sessions | A visit to the site. One person can have several. |
| Users | Individual visitors. |
| Event count | How many times a tracked action happened. |
| Provider phone clicks | Times a visitor clicked a phone number to call a provider. |
| Facility directions clicks | Times a visitor clicked for directions to a facility. |
| Directory searches | Times a visitor used the search. |
| Newsletter sign-ups | Times a visitor joined the email list. |
| Lead conversion | Share of sessions that included a phone click or a directions click. Formula: (Phone Clicks + Directions Clicks) / Sessions. |
| Source / medium | Where a visit came from, such as organic search or direct. |
| Device category | The kind of device used: desktop, mobile or tablet. |
